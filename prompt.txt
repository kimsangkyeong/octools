ocp 관리도구를 liunx 가반에서 cli로 관리할 수 있는 shell 프로그램을 만들고, remote windows 환경에서 streamlit 기반의 ui로 동일한 기능을 호출할 수 있는 프로그램을 만들었으면 좋겠어. 
linux/window 환경에 맞게 cli 메뉴와 ui 메뉴를 이용한 명령어 실행을 했으면 해.

1.요구사항

1) oc 명령어로 운영에 필요한 pod, co, mc, mcp 등 정보를 조회하고, 비정상 리소스의 라인은 빨강색으로 표시하면 좋겠어.

2) oc 운영 메뉴를 linux에서는 화면에서 cursor 혹은 번호를 선택하면 해당 명령어가 실행되어 결과를 출력하고, windows에서는 ui에서 마우스 클릭 등으로 메뉴 선택할 수 있도록 해야하. ( 메뉴 종류는 동일 )

3) 메뉴 목록은 기능확장에 따라서 쉽게 추가할 수 있도록 함수 형식으로 기능 추가가 되도록 프로그램이 되었으면 좋겠어.

4) 기본적인 oc 명령어를 가지고 먼저 프로그램을 작성해줘. 이후에 추가 기능 보완 요청하도록 할께.

5) 메뉴가 많아지는 경우를 고려하여, 화면을 이분하여 메뉴 목록을 관리하고, page 관리가 필요하는 페이지를 이동할 수 있도록 처리해줘.

6) oc get pod -A 와 oc get pod -n <ns> 의 case가 존재하는데, enter를 입력하면, oc get ns 로 목록을 추출한 후 메뉴에서 선택하도록 하는 SUB MENU 선택할 수 있도록 해줘.

7) 운영에 필요한 메뉴를 검토해서 최소 10 개 이상으로 초기 메뉴를 제공해줘

=> windows에서 호출시 서버에서 웹서버 구성등이 필요할 텐데 관련 내용도 함께 정리가 되도록 해줘
