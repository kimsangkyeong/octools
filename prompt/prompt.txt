####################################################################################################
## 질문 이력 관리 인덱스 (prompt index)
##--------------------------------------------------------------------------------------------------
## 이 폴더는 사용자와 Kiro 간 질문/요구사항 이력을 프로그램별로 분리하여 관리한다.
## 각 질문에는 순번과 날짜가 자동으로 부여되며, Kiro가 기록한 항목은 [작업자: Kiro]로 표시한다.
####################################################################################################

[관리 규칙]
1. 프로그램별로 파일을 분리하여 관리한다.  (예: prompt/ocptools.md, prompt/ocpcatalog.md)
2. 질문 기록 형식:
     =============== [식별자] #순번 YYYY-MM-DD
     [작업자: Kiro]
     (질문 내용)
   - 식별자 : 프로그램/프로젝트 구분자 (예: ocptools, octools)
   - 순번   : 해당 식별자 파일 내 질문 순번 (#001 부터 증가)
   - 날짜   : 질문 기록 일자
3. 사용자가 질문 앞에 [식별자] 를 적어주면 해당 식별자 파일에 기록한다.
     예) "[ocptools] tcpdump 필터를 추가해줘"
4. 식별자가 없는 새 프로그램 요청 시, Kiro가 적절한 식별자를 제안하고 새 파일을 만든다.

[프로그램 목록]
| 식별자     | 파일                    | 설명                                                        |
|------------|-------------------------|-------------------------------------------------------------|
| ocptools   | prompt/ocptools.md      | OCP/Podman/Network 운영 명령어 학습형 통합 CLI (단일 shell) |
| ocpcatalog | prompt/ocpcatalog.md    | OCP release/operator 카탈로그 조회 + 업그레이드 영향도 분석 (ocp_list.sh) |

[공통 개발 규칙 - 최초 요청 시 사용자가 지정]
- 요구사항문서 + 목표 아키텍처/설계서 작성 (표/차트/플로우 포함).
- 오류 수정 또는 신규 요구사항 발생 시 문서와 프로그램 모두 리비전.
- 문서 산출물은 md 2가지로 작성.
- 프로그램 언어는 bash, python 사용.
